# Day 2 — HR Analytics Using Excel

## 🎯 Objective

As part of my 90-Day Data Analytics Internship Preparation Journey, I worked with an HR Analytics dataset to practice Excel formulas, conditional formatting, data validation, and business-oriented data analysis.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- IF & Nested IF formulas
- Conditional Formatting
- Data Validation
- Sorting & Filtering

## 📊 Dataset

The dataset contains employee-level HR information such as:

- Employee ID
- Age
- Department
- Job Role
- Monthly Income
- Overtime
- Performance Rating
- Training
- Years at Company
- Job Satisfaction
- Work-Life Balance
- Attrition

## 🔧 Tasks Completed

### 1. Data Preparation
- Reviewed the raw HR dataset
- Selected relevant columns for analysis
- Preserved the original dataset separately

### 2. IF & Nested IF
Created calculated columns for:

- Attrition Risk
- Performance Category
- Salary Category
- Training Recommendation

### 3. Conditional Formatting
Used conditional formatting to identify important employee patterns.

### 4. Data Validation
Created controlled input/dropdown fields for HR analysis.

### 5. Pivot Table Analysis

Answered business questions such as:

- Which department has the highest number of employees?
- Which job role has the highest attrition?

## 💡 Key Insights

- Research & Development has the highest number of employees.
- Laboratory Technician has the highest attrition among the analyzed job roles.
- Attrition and overtime can be explored together to identify potential employee-risk patterns.

## 🧠 Key Learning

The biggest lesson from Day 2 was that creating a Pivot Table is not enough.

An analyst must verify whether the calculation actually answers the business question.

My workflow:

**Question → Filter → Calculate → Verify → Interpret → Insight**
