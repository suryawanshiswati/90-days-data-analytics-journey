# Day 1 — Retail Sales Data Analysis Using Excel

## 🎯 Objective

As part of my 90-day Data Analytics internship preparation journey, I worked with a retail sales dataset to practice Excel data cleaning, data preparation, and basic business analysis.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Sort & Filter
- Conditional Formatting
- Data Validation
- Data Cleaning

## 📊 Dataset

The dataset contains retail sales information including:

- Order ID
- Order Date
- Product
- Category
- Region
- Customer Type
- Payment Method
- Quantity
- Unit Price
- Total Sales

## 🧹 Data Cleaning

The following tasks were performed:

- Checked for duplicate records
- Investigated missing values
- Corrected inconsistent data
- Standardized customer type values
- Checked date and numerical formatting
- Prepared the dataset for analysis

## 🔎 Excel Analysis

I practiced:

- Sorting
- Filtering
- Conditional Formatting
- Pivot Tables
- Aggregating Total Sales
- Comparing sales across categories

## 📈 Business Questions

I used Pivot Tables to answer:

1. Which region generated the highest sales?
2. Which customer type generated the highest sales?
3. Which payment method generated the highest sales?
4. Which month generated the highest sales?

## 💡 Key Learnings

- Data cleaning is an important part of the analytics process.
- Excel functions are useful, but knowing when to apply them is more important.
- Pivot Tables can quickly summarize large datasets.
- Data analysis should start with a business question rather than simply manipulating data.

## 🧠 Reflection

Before starting this challenge, I had learned several Excel concepts through tutorials but lacked confidence in applying them.

This exercise helped me move from learning Excel features to actually using Excel to solve business questions.
